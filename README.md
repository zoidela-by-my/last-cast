# Last Cast

A cozy first-person fishing game — working prototype.

Fish by day from your little boat: cast, wait for the bite, reel it in. At dusk the Kappa surfaces for its cut. Survive all three days and you win the voyage.

Built with Muse.

Boat models: Kenney Watercraft Kit and Pirate Kit (https://kenney.nl) — CC0. 3D engine: Three.js (MIT).
